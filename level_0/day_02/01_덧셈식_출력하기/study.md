---

## 💡 새로 알게 된 점

- 템플릿 리터럴은 백틱(``) 안에서 동작

solution2.js 파일 참고

1. line.split(' '): 입력받은 문자열을 공백 기준으로 잘라 ["4", "5"] (문자열 배열) 생성

2. .map(Number): 배열 안의 문자열들을 전부 한 번에 숫자로 바꾼 [4, 5] (숫자 배열) 생성

   -> .map(Number) 의 경우 .map(x => Number(x))의 축약 표현

3. [a, b] = ...: 숫자 배열의 첫 번째 값 4는 a에, 두 번째 값 5는 b에 각각 할당

4. `${a} + ${b} = ${a + b}`: 이미 숫자로 변환된 a, b를 템플릿 리터럴로 깔끔하게 출력

즉, .split() 으로 인해 문자열 배열이 생성되고 .map() 메서드는 배열 안의 모든 원소를 순회하며 지정한 콜백함수를 호출(Number)해 문자열 배열이 숫자 배열로 변환되어 각각 a,b에 할당되는 것
