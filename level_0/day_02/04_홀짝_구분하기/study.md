# ✍️ 학습 및 오답 노트

## ❌ 처음에 실수했던 부분

- **템플릿 리터럴 문법 및 공백 처리 실수:** `console.log(n, "is even")` 처럼 `console.log` 내부에서 쉼표(`,`)를 사용하면 자동으로 공백이 추가되어 원하는 출력 결과와 달라지는 문제 발생.
- **문자열 연결 연산자(`+`) 공백 누락:** `n + "is even"`으로 작성하여 숫자와 문자열 사이의 공백이 누락된 채 붙어서 출력(`100is even`)되는 오답 발생.

## 💡 새로 알게 된 점

- **`console.log()`의 인자 구분(`,`) 동작:** 쉼표로 인자를 전달하면 자동으로 공백(space) 한 칸이 포함되어 출력됨. 디버깅 목적이 아니라면 알고리즘 채점 시 완성된 하나의 문자열로 전달하는 것이 안전함.
- **삼항 연산자 활용:** 단순 조건문(`if-else`) 대신 삼항 연산자를 활용하면 조건에 따른 문자열 값을 가볍게 분기 처리할 수 있음.

---

## 🔍 풀이 접근법 및 성능 비교

- **템플릿 리터럴 방식 (추천):** 백틱(`` ` ``)을 사용하는 템플릿 리터럴(`${n} is even`) 방식이 문자열 가독성이 가장 뛰어나고, 공백 관련 실수를 방지하기에 가장 깔끔함.
- **삼항 연산자 + 템플릿 리터럴:** `${n} is ${n % 2 === 0 ? 'even' : 'odd'}` 단 한 줄로 조건 판별과 문자열 포맷팅을 동시에 처리할 수 있어 코드 길이가 대폭 줄어듦.
