# ✍️ 학습 및 오답 노트

## ❌ 처음에 실수했던 부분

문자열을 합치려는 과정에서 어떤 메서드를 사용해야할 지 바로 떠오르지 않아서

1. `map`
2. `forEach`

두가지를 떠올렸는데, `map`의 경우 새로운 배열을 반환하게 되므로 적합하지 않다고 판단하고, `forEach`를 사용하게됨

---

## 💡 새로 알게 된 점

`forEach` 외에도 배열 전용 메서드인 `join`을 사용하면 별도의 반복문이나 누적 변수를 사용하지 않더라도, 매우 간단하게 표현할 수 있음을 알게되었음

## 🔍 풀이 접근법 및 성능 비교

| 구분            | 접근법 1: `forEach` 순회                                                                      | 접근법 2: `join("")` 메서드                                                 |
| :-------------- | :-------------------------------------------------------------------------------------------- | :-------------------------------------------------------------------------- |
| **코드 형태**   | `arr.forEach(element => answer += element)`                                                   | `arr.join("")`                                                              |
| **장점**        | - 흐름이 직관적이고 직접 제어 가능<br>- 순회 중 추가 조건 처리(예: 특정 문자는 제외)가 용이함 | - 코드가 매우 간결함<br>- C++ 기반의 엔진 내부 최적화로 실행 속도가 더 빠름 |
| **단점**        | - 코드가 다소 길어지고 누적용 변수(`answer`)가 별도로 필요함                                  | - 합치는 과정 중간에 가공/조건 로직을 넣기 힘듦                             |
| **시간 복잡도** | $O(N)$                                                                                        | $O(N)$                                                                      |
| **공간 복잡도** | $O(1)$ _(결과 문자열 제외)_                                                                   | $O(1)$ _(결과 문자열 제외)_                                                 |
