# ✍️ 학습 및 오답 노트

## ❌ 처음에 실수했던 부분

`answer = str1[i] + str2[i]`라고 작성했었는데, `=`가 아니고 `+=`를 사용해야 문자열이 누적되어 연결됨.

> **이유:** `=`를 사용하면 이전 문자가 누적되지 않고 마지막 인덱스의 값으로 계속 덮어씌워짐.

---

## 그냥 = 를 사용하는 경우에는 이후 인덱스 문자 값이 연결되는 것이 아니라 덮어씌워지게됨

## 💡 새로 알게 된 점

solution2 의 다른 사람 풀이

```js
function solution(str1, str2) {
  return [...str1].map((x, idx) => x + str2[idx]).join("");
}
```

1. [...str1] (전개 구문, Spread Operator)
   문자열 str1을 한 글자씩 쪼개어 배열로 변환
   - 예시: "aaaaa" → ['a', 'a', 'a', 'a', 'a']

2. .map((x, idx) => x + str2[idx]) (map 메서드)
   배열의 각 요소(x)와 인덱스(idx)를 활용해 순회
   - x: str1의 해당 위치 문자의 값

   - str2[idx]: 같은 인덱스 위치에 있는 str2의 문자

   - 두 문자를 합쳐서 새로운 배열을 생성

   - 예시: ['a', 'a', 'a', 'a', 'a'] → ['ab', 'ab', 'ab', 'ab', 'ab']

3. .join("") (join 메서드)
   - 배열 안의 요소들을 구분자 없이 하나로 이어 붙여 단일 문자열로 합침

   - 예시: ['ab', 'ab', 'ab', 'ab', 'ab'] → "ababababab"

---

## 🔍 풀이 접근법 및 성능 비교

| 구분            | 접근법 1: 전통적인 `for` 반복문                                                             | 접근법 2: 배열 메서드 체이닝 (`map`, `join`)                               |
| :-------------- | :------------------------------------------------------------------------------------------ | :------------------------------------------------------------------------- |
| **코드 형태**   | `answer += str1[i] + str2[i]`                                                               | `[...str1].map(...).join("")`                                              |
| **작동 방식**   | 인덱스로 직접 접근하여 결과 변수(`answer`)에 차례대로 누적                                  | 문자열을 배열로 변환 후 짝을 맞춰 다시 문자열로 합침                       |
| **장점**        | - 직관적이고 연산 과정이 단순함<br>- 불필요한 중간 데이터(배열)를 만들지 않아 메모리 효율적 | - 코드가 1줄로 매우 간결함<br>- 함수형 프로그래밍 스타일로 가독성이 뛰어남 |
| **단점**        | - 반복문 제어를 위한 코드가 길어짐 (`let i = 0; ...`)                                       | - 임시 배열을 생성하므로 가비지 컬렉션 부담이 다소 발생                    |
| **시간 복잡도** | $O(N)$                                                                                      | $O(N)$                                                                     |
| **공간 복잡도** | $O(1)$ _(결과 문자열 제외)_                                                                 | $O(N)$ _(임시 배열 생성)_                                                  |
