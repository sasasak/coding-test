# ✍️ 학습 및 오답 노트

## ❌ 처음에 실수했던 부분

- 문자열을 이어 붙일 변수를 `0`으로 초기화함: 숫자 `0`에 문자열을 `+=`하면 문자열 연결로 처리되어 `"03"`, `"042"`처럼 앞에 `0`이 붙은 문자열이 만들어짐. `Number()`로 변환하면 앞의 0이 사라져 우연히 값은 맞지만, 의도가 불분명하고 헷갈리기 쉬움. (이어 붙일 문자열은 빈 문자열 `''`로 초기화해야 함)
- 문자열을 담는 변수 이름을 `odd_list`, `even_list`로 지음: 실제로는 배열(list)이 아니라 이어 붙인 문자열이라, 이름과 타입이 맞지 않아 읽을 때 헷갈릴 수 있음. (`odd_str`, `even_str`처럼 담는 값의 타입에 맞게 이름 짓기)

## 💡 새로 알게 된 점

- 누적 변수의 초기값은 "아무것도 안 했을 때의 상태"를 나타내는 값으로, 담을 값의 타입에 맞춰야 함.

| 누적하는 것        | 초기값 | 이유                    |
| ------------------ | ------ | ----------------------- |
| 숫자 합            | `0`    | `0 + x = x`             |
| 숫자 곱            | `1`    | `1 * x = x`             |
| 문자열 이어 붙이기 | `''`   | `'' + 'a' = 'a'`        |
| 배열에 담기        | `[]`   | 비어 있는 배열에서 시작 |

- JS에서 숫자와 문자열을 `+`로 연결하면 문자열 연결이 우선되므로, 초기값의 타입이 결과의 타입을 결정함.
- `null`은 누적 초기값으로 쓸 수 없음: 문자열에 쓰면 `"null3"`처럼 `null`이 글자 그대로 섞이고, 곱에 쓰면 `0`으로 취급되어 결과가 항상 `0`이 됨. `null`은 "값이 아직 정해지지 않았다"는 표시용임.
- 문자열(`''`)에 숫자를 `+=`하면 `String()` 없이도 자동으로 문자열로 변환되어 이어 붙여짐.

## 🔍 풀이 접근법 및 성능 비교

```javascript
function solution(num_list) {
  let odd_str = "";
  let even_str = "";

  for (let i = 0; i < num_list.length; i++) {
    if (num_list[i] % 2 === 0) {
      even_str += num_list[i];
    } else {
      odd_str += num_list[i];
    }
  }

  return Number(even_str) + Number(odd_str);
}
```

- 배열을 한 번만 순회하며 홀수/짝수를 각각 문자열로 이어 붙인 뒤, 마지막에 숫자로 변환해 더하는 O(n) 방식.
- `Number("351")`처럼 문자열을 숫자로 바꿔야 `"351" + "42"`가 `"35142"`(문자열 연결)가 되지 않고 `393`(숫자 덧셈)이 됨.
