## 💡 새로 알게 된 점

- 조건에 따라 두 값 중 하나를 반환하는 단순 분기는 if-else보다 삼항연산자로 한 줄에 처리하는 게 더 간결함.

## 🔍 풀이 접근법 및 성능 비교

```javascript
function solution(a, b, flag) {
  return flag ? a + b : a - b;
}
```

- flag가 true/false 두 가지뿐이고 로직도 단순해서 삼항연산자 한 줄로 충분함.
- 시간 복잡도 O(1)
