# ✍️ 학습 및 오답 노트

## ❌ 처음에 실수했던 부분

**삼항 연산자의 조건식 평가 오해**

- `const solution = (num, n) => num % n ? 1 : 0` 과 같이 작성 시, 배수일 때 나머지가 `0`이 나와 조건문에서 **Falsy(거짓)**로 평가됨.
- 이로 인해 의도와 반대로 **배수일 때 `0`, 배수가 아닐 때 `1`이 반환되는 오류**가 발생함.

```javascript
// ❌ 잘못된 접근 (배수일 때 0 반환)
const solution = (num, n) => (num % n ? 1 : 0);

// ✅ 올바른 조건식 표현
const solution = (num, n) => (num % n === 0 ? 1 : 0);
```

---

## 💡 새로 알게 된 점

1. **JavaScript의 Truthy와 Falsy**
   - 숫자 `0`은 조건문에서 `false`로 평가되고, `0`이 아닌 숫자는 `true`로 평가됨.
2. **삼항 연산자를 활용한 단축 표현 작성법**
   - **순서 뒤집기:** `num % n ? 0 : 1` (나머지가 있으면 0, 없으면 1)
   - **명시적 비교:** `num % n === 0 ? 1 : 0`
3. **불리언 형변환(Type Casting) 활용**
   - 단항 플러스 연산자(`+`)나 `Number()`를 사용하여 `true/false`를 `1/0`으로 변환 가능: `+(num % n === 0)`

---

## 🔍 풀이 접근법 및 성능 비교

| 구분                   | 작성한 코드                                   | 가독성     | 특징 및 비고                                    |
| :--------------------- | :-------------------------------------------- | :--------- | :---------------------------------------------- |
| **명시적 if-else**     | `if (num % n === 0) return 1; else return 0;` | ⭐⭐⭐⭐⭐ | 의도가 명확하며 읽고 이해하기 가장 쉬움         |
| **삼항 연산자**        | `num % n === 0 ? 1 : 0`                       | ⭐⭐⭐⭐   | 조건식이 명확하고 한 줄로 깔끔하게 작성 가능    |
| **단항 연산자 형변환** | `+(num % n === 0)`                            | ⭐⭐⭐     | 코드가 매우 짧으나 암묵적 형변환 개념 이해 필요 |

> **성능 비교:**  
> 세 방식 모두 단순 산술 및 비교 연산이므로 시간 복잡도는 $O(1)$로 동일하며, 실질적인 실행 속도 차이는 없으나, 가독성이 뛰어난 구문을 사용하는것이 좋다!
